# LLM 모델 조사 및 비교

## 1. 목적

World Vision AI Agent 서비스에 적용 가능한 LLM을 조사하고,
동일한 테스트 조건에서 비교하여 프로젝트에 적합한 모델을 선정한다.

---

## 2. 평가 항목

- 한국어 응답 품질
- 요약 능력
- 구조화 출력 준수
- Hallucination 억제
- Context 준수
- 응답 속도
- API 연동 편의성
- 비용

---

## 3. OpenAI 테스트

### 테스트 결과

| 테스트 항목 | 결과 | 응답 시간 |
|---|---|---:|
| 일반 질의 | 성공 | 3.92초 |
| 요약 | 성공 | 1.79초 |
| 구조화 출력 | 성공 | 2.76초 |
| Hallucination 방지 | 성공 | 1.47초 |

### 결과 분석

- 한국어 응답이 자연스럽게 생성됨
- 요약 결과가 요구한 형식을 준수함
- JSON 구조화 출력 성공
- 제공되지 않은 정보에 대해 추측하지 않고 답변을 제한함
- 주어진 Context를 기반으로 답변함

## 4. Gemini 테스트

### 테스트 결과

| 테스트 항목 | 결과 | 응답 시간 |
|---|---|---:|
| 일반 질의 | 성공 | 26.76초 |
| 요약 | 성공 | 11.92초 |
| 구조화 출력 | 성공 | 4.67초 |
| Hallucination 방지 | 성공 | 4.35초 |
| Context 준수 | 성공 | 3.52초 |

**성공: 5/5**  
**평균 응답 시간: 10.24초**

### 결과 분석

- 5개 테스트 모두 정상적으로 수행됨
- 요약 결과가 요구사항을 준수함
- JSON 구조화 출력 성공
- 제공되지 않은 정보에 대해 추측하지 않고 답변을 제한함
- 주어진 Context를 기반으로 답변함
- 일부 요청에서 503 서버 혼잡이 발생하여 자동 재시도가 수행됨
- 초기 테스트에서는 Gemini Free Tier 요청 제한으로 429 오류가 발생했으나,
  테스트 간 대기 시간을 적용한 이후 전체 테스트에 성공함

### 참고

일반 질의(Test 1)는 별도의 Context 제한이 없는 테스트이므로
월드비전과 관련된 추가 정보를 모델 자체 지식으로 생성하였다.
따라서 해당 테스트는 사실 정확성보다는 한국어 응답 품질 평가용으로 사용한다.

## 5. Claude 테스트

### API 연동 결과

Anthropic API Key 설정 및 Claude API 연동 코드 구현까지 완료하였다.

동일한 5개 테스트 케이스를 실행하였으나,
Anthropic API 계정의 크레딧 부족으로 실제 모델 응답 테스트를 수행하지 못하였다.

### 테스트 결과

| 테스트 항목 | 결과 |
|---|---|
| 일반 질의 | 테스트 불가 - API Credit 부족 |
| 요약 | 테스트 불가 - API Credit 부족 |
| 구조화 출력 | 테스트 불가 - API Credit 부족 |
| Hallucination 방지 | 테스트 불가 - API Credit 부족 |
| Context 준수 | 테스트 불가 - API Credit 부족 |

### 확인된 오류

`Your credit balance is too low to access the Anthropic API.`

따라서 Claude는 API 연동 구조까지 확인하였으며,
실제 응답 품질과 응답 속도 비교에서는 제외하였다.

## 7. 기본 LLM 선정

현재 프로토타입에서는 OpenAI 모델을 기본 LLM으로 사용한다.

동일한 테스트 환경에서 OpenAI와 Gemini 모두
요약, 구조화 출력, Hallucination 방지, Context 준수 테스트를 통과하였다.

OpenAI는 5개 테스트에서 별도의 API 오류 없이 동작하였으며
평균 응답 시간이 2.31초로 측정되었다.

Gemini 역시 최종적으로 5개 테스트를 모두 통과했지만,
테스트 과정에서 503 서버 혼잡 및 Free Tier 429 Rate Limit이 발생하였다.

Claude는 API 연동 코드까지 구현하였으나
API Credit 부족으로 실제 응답 테스트를 수행하지 못하였다.

따라서 현재 프로토타입 단계에서는
실제 테스트 결과와 API 안정성을 고려하여 OpenAI를 기본 모델로 선정한다.

단, 본 결과는 현재 테스트 환경에서 수행한 프로토타입 비교 결과이며,
향후 비용, 사용량, 서비스 요구사항에 따라 모델을 재평가할 수 있다.
