# LLM 모델 조사 및 비교

## 1. 목적

World Vision AI 서비스에 적용 가능한 LLM을 조사하고,
동일한 평가 기준을 통해 프로젝트에 적합한 모델을 선정한다.

## 2. 비교 대상

- OpenAI GPT 계열
- Google Gemini 계열
- Anthropic Claude 계열

## 3. 평가 기준

1. 한국어 응답 품질
2. 지시사항 준수
3. Context 준수
4. Hallucination 억제
5. 구조화된 출력 안정성
6. 응답 속도
7. API 연동 편의성
8. 비용

## 4. 테스트 조건

모든 모델에 동일한 Prompt를 입력하여 비교한다.

### Test 1 - 일반 질의

월드비전 AI 서비스가 필요한 이유를
3가지로 간단하게 설명해주세요.

### Test 2 - 요약

제공된 내용을 핵심 내용만 3줄로 요약해주세요.

### Test 3 - 구조화 출력

다음 정보를 JSON 형식으로 출력해주세요.

- 부서명
- 요청사항
- 우선순위

### Test 4 - Hallucination 방지

제공된 정보만 사용해서 답변하고,
확인할 수 없는 내용은 추측하지 말고
"제공된 정보에서 확인할 수 없습니다."라고 답해주세요.

질문:
월드비전의 2027년 총매출은 얼마인가요?

### Test 5 - Context 준수

아래 Context만 사용해서 질문에 답해주세요.
Context에 답이 없으면 없다고 답해주세요.
