# 최종 QA 및 발표 점검표

## QA 완료 기준

| 구분 | 확인 항목 | 통과 기준 |
| --- | --- | --- |
| 공통 | 자동 테스트 | `python -m pytest demo/tests -q -p no:cacheprovider`가 모두 통과한다. |
| 공통 | 배포 서비스 | 최종 URL에서 새로고침 후에도 첫 화면과 세 탭이 정상 표시된다. |
| 검색 | 근거 기반 답변 | PDF 또는 TXT 업로드 후 질문하면 답변과 `[S번호]` 출처가 함께 표시된다. |
| 문서 작성 | 초안 생성 | 업로드 자료를 근거로 초안·출처가 생성되고 Markdown 다운로드가 된다. |
| 회의 업무 | 정상 회의록 | 최대 100MB 지원 형식의 녹음과 제목을 넣으면 전사 원문·회의록·다운로드가 제공된다. |
| 회의 업무 | 대용량 파일 | 25MB 초과 100MB 이하 파일은 자동 분할 전사되고, 100MB 초과 파일은 화면에서 차단된다. |
| 오류 처리 | API 키 미설정 | 검색·문서 작성·회의 업무 모두 `AI 서비스 연결 정보가 설정되지 않았습니다.`만 표시하며 키 이름·스택 트레이스를 노출하지 않는다. |
| 배포 | 비밀값 | GitHub에 API 키가 없고, 배포 플랫폼의 Secrets에만 `OPENAI_API_KEY`가 설정되어 있다. |

## 역할별 최종 점검

### Product Owner

- 발표 자료는 5쪽 이내로 고객 문제, 핵심 가치, 3개 기능, 실제 데모, 팀 기여를 연결한다.
- 발표 전 사용자 인수 테스트를 1회 수행하고, 발견된 문제와 처리 결과를 팀에 공유한다.
- 최종 URL, GitHub 링크, PPT, 팀 과제 최종 보고서를 제출 목록과 대조한다.

### AI Solution Architect

- 아래 `구현됨`과 `설계만 됨`을 구분해 아키텍처 그림·발표 설명을 실제 배포 서비스와 일치시킨다.
- 구현하지 않은 항목은 숨기지 말고, 확장 설계 또는 후속 과제로 명확히 표기한다.

### AI Engineer

- 로컬과 배포 환경에서 검색, 문서 작성, 회의 업무를 각각 한 번씩 수행한다.
- 25MB 초과 녹음, 미지원 확장자, 빈 제목, API 키 미설정 상태를 점검한다.
- 최종 파라미터는 `chunk_size=1000`, `chunk_overlap=150`, `top_k=5`, 벡터/BM25 가중치 `0.7/0.3`으로 코드와 발표 자료에 동일하게 적는다.

### Cloud/Infra Engineer

- Streamlit Cloud Secrets의 `OPENAI_API_KEY` 존재 여부와 배포 로그를 확인한다.
- `.streamlit/config.toml`의 `maxUploadSize = 100`이 배포 후 적용됐는지 124MB 파일로 확인한다.
- 발표 직전 최종 URL을 열어 검색 또는 문서 작성 1회를 실행해 콜드 스타트를 해소한다.
- 현재 MVP의 업로드 문서·벡터 인덱스는 세션 메모리 기반이므로 재시작 뒤 영구 보존 대상이 아님을 발표 시 명확히 설명한다.

## 아키텍처: 실제 구현과 확장 설계의 구분

| 상태 | 항목 |
| --- | --- |
| 구현됨 | Streamlit 웹 UI, PDF/TXT 텍스트 추출, OpenAI 임베딩, FAISS + BM25 하이브리드 검색, OpenAI 답변/문서 초안 생성, 음성 전사와 회의록 생성, 출처 표시 및 Markdown 다운로드 |
| 구현됨 | API 키 미설정 공통 안내, 음성 형식·25MB 제한, 업로드 파일의 세션 메모리 처리 |
| 설계/후속 과제 | FastAPI 별도 서버, 사용자 인증·권한 관리, Salesforce·Tableau·Teams·Outlook 연동, Gemini·Claude 모델 연동, 영구 문서/메타데이터 저장소 |

발표용 아키텍처 그림에는 `설계/후속 과제` 영역을 점선 또는 `향후 확장`으로 표시하고, 현재 MVP의 실제 요청 경로는 다음처럼 설명한다.

```text
사용자 → Streamlit UI → Python workflow
       → (문서) OpenAI 임베딩 → FAISS + BM25 → OpenAI 응답 생성
       → (회의) OpenAI 전사 → OpenAI 회의록 생성
```
